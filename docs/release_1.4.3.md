# MDRK Builder 1.4.3 Internal

Исправленная Windows-сборка для внутреннего использования. GitHub служит каналом
скачивания программы; условия Internal Use сохранены.

## Исправления

- Устранена медленная отрисовка таблицы МКФ на Windows: сетка использует штатную
  рамку Tk вместо повторяющегося изображения в каждой ячейке. Проверка сборки теперь
  открывает видимые таблицы МДРК-1, МДРК-2 и выписки, прокручивает их и переключает
  документы. На предыдущем варианте эта проверка превысила лимит 25 секунд.
- МДРК-2 и выписной эпикриз можно готовить в любом порядке. Отсутствие готового
  МДРК-2 больше не выдаётся как проблема. Сформированные билдером DOCX и их копии
  не меняют данные при повторном сканировании. Внешний МДРК остаётся необязательным
  дополнительным источником.
- Явно записанный результат достижения цели читается из выписки МИС или итогового
  осмотра врача с сохранением источника. Исходный план не превращается в результат.
- Автосохранение и команда сохранения черновика больше не создают JSON в папке
  пациента. Черновики находятся в `%LOCALAPPDATA%\MDRK Builder\drafts` текущего
  пользователя. Старый `.mdrk draft.json` переносится при открытии папки, если
  локальной копии ещё нет; удаление выполняется только после её проверки.
  Посторонние JSON не затрагиваются.

## Установка

Скачайте `MDRK_Builder-1.4.3-Internal-windows-x64.zip`, распакуйте весь архив
и запустите `MDRK_Builder.exe`. Python и установка не требуются. Для чтения DOC/RTF
нужен настольный Microsoft Word. Черновики доступны на том же компьютере;
готовые DOCX сохраняйте кнопкой «Сохранить документ».

## Проверка

Локально прошли 435 тестов, компиляция и privacy gate. Проверены оба порядка
создания итоговых документов, неизменность источников, перенос старого черновика
и сохранение правок при ошибке переноса. Публикация ZIP выполняется после тестов
Windows, сборки EXE, видимого UI smoke-test, записи/повторного чтения DOCX и
проверки состава архива.

Преобразование DOC/RTF через настольный Microsoft Word на целевом компьютере
без Python ещё не проверено; выпуск остаётся предварительным Internal Use.
