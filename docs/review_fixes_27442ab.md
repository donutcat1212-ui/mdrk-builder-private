# Исправления по ревью 27442ab

Статус: **success — исправления исходного кода и локальная проверка**.

| Замечание | Изменение |
|---|---|
| P1: правка МКФ переносится на другую конечность | Явная идентичность каждого типа строки. Для МКФ используется доменный ключ с описанием; `origin_key` сохраняет связь с источником при переименовании. Неоднозначные дубликаты больше не сопоставляются по позиции: сохраняется ручная группа и показывается предупреждение. |
| P1: отменённая правка возвращается при переходе между документами | `SharedTableEditor` владеет транзакцией редактирования и общей историей МДРК/выписки. Изменение отражается в обеих проекциях сразу; Undo/Redo восстанавливает обе таблицы. Переход между вкладками больше не объединяет таблицы. Команды доступны в меню «Правка». Правки выписки применяются и при последующей первой загрузке МДРК. |
| P1: данные предыдущего пациента попадают в новый JSON | Единая очистка рабочего эпизода удаляет исходные копии, промежуточный ввод и историю всех панелей. `WorkspaceDraft` содержит только загруженные документы. При сохранении и восстановлении проверяется принадлежность моделей и исходных копий выбранной папке. Старые словарные черновики читаются с исключением незагруженных панелей. |
| P2: исчезает предупреждение о неполной паре МКФ | Общая проверка `icf_assessment_issues` используется МДРК и выпиской и пересчитывает пропуски по текущим оценкам. Для описательных строк `Pf` числовые оценки не требуются. |
| P2: Tab создаёт строку | Навигация использует видимые редактируемые столбцы и отдельный предикат строки данных. Callback активации выполняется только при явном открытии строки. |
| P2: две панели и неявные mixin-контракты | Конкретные `DischargeSummaryPanel` и `ReverseSheetPanel` разделены. `DischargeTableEditing` и `WorkspaceState` удалены; панели сами захватывают, восстанавливают и очищают своё состояние. Сохранение получает типизированный снимок через явные callbacks. |

Проекция `DischargeSummaryDraft` сохранена согласно ADR 0001: у выписки собственная клиническая граница и поля, которых нет в снимке МДРК. Единой стала транзакция изменения общих таблиц. Writer по-прежнему получает готовую проекцию; новые зависимости не добавлялись.

Проверки находятся в `tests/test_review_regressions.py`: пять первоначальных воспроизведений и дополнительные сценарии идентичности, неоднозначных дубликатов, Undo/Redo, реального меню, поздней загрузки МДРК, видимых столбцов, старых черновиков и отклонения чужой исходной копии до изменения интерфейса. Использованы синтетические данные и настоящие Tk-виджеты.

Windows EXE и запуск с настольным Microsoft Word в этой сессии не проверены. Версия программы не изменялась.
