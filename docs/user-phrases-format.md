# Переносимый файл фраз врача

`user_phrases.json` — пользовательский файл рядом с EXE. Отсутствие файла
означает пустые списки; первый успешный вызов «+ Добавить» создаёт файл.
Готовых фраз нет. Программа читает список заново при открытии меню.

Фразы разделены по полям документа. Одноимённые поля МДРК и выписки используют
один список. `conclusion` — общий список для заключений специалистов.
Произвольный текст, Unicode и переносы строк сохраняются. Фраза вставляется
только при явном выборе врача; добавление в список не изменяет документ.

## Стабильный контракт v1

Кодировка UTF-8; чтение допускает BOM. Версия схемы независима от версии EXE.

```json
{
  "schema_version": 1,
  "fields": {
    "conclusion": ["Собственная фраза врача.\nВторая строка."]
  }
}
```

- `fields` — объект со стабильными идентификаторами полей; значения — списки строк.
  Порядок строк совпадает с порядком меню. Повторное добавление той же строки
  в то же поле не создаёт дубликат. Удаление затрагивает только выбранную строку.
- Будущие версии программы обязаны читать v1. Идентификаторы полей и значения
  существующих ключей нельзя переопределять; при переименовании поля нужна
  совместимость с его сохранённым идентификатором.
- Дополнительные ключи верхнего уровня и неизвестные поля сохраняются при записи.
  Несовместимая схема требует нового номера версии и отдельного преобразования;
  исходный файл нельзя заменять до успешной проверки преобразования.
- Текущая версия отказывается изменять повреждённый файл или неизвестную версию
  схемы, сообщает ошибку и не подменяет данные пустым списком.
- Перед изменением файл перечитывается под общей блокировкой. Запись идёт во
  временный файл с последующей атомарной заменой. При ошибке сохранения окно
  добавления остаётся открытым вместе с введённым текстом.

Регрессии совместимости, переноса, одновременной записи и сбоев:
`tests/test_user_phrases.py`. Фикстура v1 остаётся обязательной для будущих версий.

## Обновление программы

Поставка никогда не содержит `user_phrases.json`: распаковка обновления в ту же
папку сохраняет пользовательские фразы. Для новой папки достаточно скопировать
JSON рядом с EXE. Служебная блокировка `user_phrases.json.lock` создаётся заново.
При использовании EXE из общей сетевой папки фразы общие для её пользователей.
Файл пользователя, блокировки и временные файлы не входят в Git и поставку.
