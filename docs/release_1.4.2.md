# MDRK Builder 1.4.2

Публичная предварительная Windows-сборка с исправлениями редактора и сохранения черновиков.

## Исправлено

- Ручная правка домена МКФ остаётся у нужной стороны/конечности после перестановки строк источника. Переименование сохраняет связь с исходной записью; неоднозначные дубликаты требуют просмотра.
- Undo/Redo согласован между МДРК и выпиской. Переключение документов больше не возвращает отменённые значения. Команды доступны в меню «Правка».
- Черновик нового эпизода не сохраняет поля, исходные копии и историю предыдущего пациента. Старые черновики поддерживаются; чужая папка исходных данных отклоняется до изменения интерфейса.
- Предупреждение об отсутствующей исходной или повторной оценке МКФ сохраняется до заполнения соответствующей оценки.
- Tab/Shift+Tab переходят между видимыми ячейками и не создают лишних строк.
- Панели выписки и оборотного листа разделены; сохранение получает типизированное состояние документов.

## Установка

Скачайте Windows x64 ZIP из Assets и распакуйте его целиком. Запустите `MDRK_Builder.exe`; установка Python не нужна. Для чтения DOC/RTF требуется настольный Microsoft Word. Для DOCX Word не нужен на этапе считывания.

Перед обновлением сохраните предыдущую программу и рабочие черновики. Документы пациентов, созданные DOCX и заполненный `issues.txt` не публикуйте в GitHub.

## Проверка

Локально прошли 424 теста, включая 17 регрессионных, компиляция и privacy gate. Публикация ZIP выполняется после Windows CI: тесты, сборка EXE, запуск упакованного интерфейса, создание и повторное чтение DOCX, проверка состава поставки.

Проверка DOC/RTF с установленным настольным Microsoft Word на целевом компьютере без Python ещё не выполнена, поэтому версия отмечена как предварительная. Сформированные медицинские документы требуют проверки специалистом.
