MDRK BUILDER {{VERSION}} INTERNAL
Внутренний пилот. Для использования в защищённой сетевой папке отделения.

НАЗНАЧЕНИЕ И УСЛОВИЯ ИСПОЛЬЗОВАНИЯ
Программа — локальный необязательный инструмент подготовки редактируемого проекта документа МДРК. Она автоматически переносит и форматирует данные из выбранных документов.

Результат может содержать пропуски или ошибки распознавания и должен быть проверен перед подписанием и включением в медицинскую документацию. Программа не выполняет диагностику, не назначает лечение и не заменяет профессиональное решение специалиста.

Программное обеспечение предоставляется «как есть», без гарантии безошибочного формирования документа. Решение об утверждении и использовании результата принимает проверивший его специалист.

БЫСТРЫЙ СТАРТ
1. Не выносите эту папку за пределы защищённой сети отделения.
2. Запустите MDRK_Builder.exe. Python и установка программы не требуются.
3. Выберите папку эпизода. Сканирование начнётся автоматически.
4. Выберите в верхней строке МДРК-1, МДРК-2, оборотный лист или выписной эпикриз.
5. Проверьте и исправьте данные прямо в полях и таблицах, затем нажмите «Сохранить документ».
6. Откройте и проверьте готовый DOCX перед подписанием.

Двойной клик или F2 редактирует ячейку, Delete удаляет строку. В полях и таблицах по правой кнопке мыши доступно меню копирования, вставки, вырезания и выделения. Неподтверждённые даты остаются пустыми.

Для полужирного текста выделите фрагмент и выберите «Полужирный» в меню правой кнопки мыши. Горячая клавиша Ctrl+B также работает.

В меню «Фразы» изначально нет готовых текстов. Нажмите «+ Добавить», введите свою фразу (можно несколько строк) и нажмите «Сохранить». Фраза появится в списке соответствующего поля; выбор фразы вставляет её в текст. Удалить фразу можно через пункт «Удалить» этого меню.

Фразы хранятся в user_phrases.json рядом с MDRK_Builder.exe. Файл создаётся при первом добавлении. При обновлении в той же папке оставьте его на месте; при переносе программы скопируйте этот файл рядом с новым EXE. В архив обновления он не включён, поэтому не перезаписывается при распаковке. Формат файла имеет отдельную версию и сохраняется совместимым с будущими выпусками. Служебный файл user_phrases.json.lock переносить не требуется. При общей сетевой папке список фраз общий для работающих из неё врачей.

Код новой строки МКФ автоматически определяет секцию. Нераспознанный код попадает в «Персональные факторы». Строку можно перетащить в любую секцию.

МДРК-2 и выписной эпикриз можно готовить в любом порядке. Готовый файл МДРК-2 для выписки не требуется.

СКФ выводится только в МДРК-1 при поступлении. В МДРК-2 и выписке этот пункт исключён.

МДРК-2 имеет время 11:00, выписка — 12:00. Данные для обоих документов отбираются до конца указанного дня независимо от времени источника внутри этого дня. Время МДРК-1 редактируется. При изменении календарной даты данные пересчитываются с сохранением ручных правок.

Рабочие черновики и автосохранение хранятся только на этом компьютере: %LOCALAPPDATA%\MDRK Builder\drafts. Служебный JSON в папке пациента не создаётся. Старый черновик переносится при открытии папки после проверки локальной копии. На другом компьютере эти правки недоступны; готовые документы сохраняйте кнопкой «Сохранить документ».

ОБРАТНАЯ СВЯЗЬ
Отзывы из окна программы добавляются в issues.txt рядом с EXE. Не переименовывайте и не удаляйте этот файл; у пользователей должно быть право записи в сетевую папку. Если отзыв содержит персональные или медицинские сведения, issues.txt должен оставаться в защищённой папке с ограниченным доступом.

СИСТЕМНЫЕ ТРЕБОВАНИЯ
